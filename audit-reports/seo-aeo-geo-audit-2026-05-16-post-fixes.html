The remaining 6 points

These three areas cap at 144/150 from code alone. Each one requires human work outside the codebase.

Off-site presence: -4

Brands get 6.5× more AI citations from third-party profiles than their own domain. Currently the Organization sameAs includes only X + LinkedIn. To unlock the full 10 points:

  • Create a Clutch profile (free) — primary B2B services directory.
  • Create a G2 profile (free) — primary B2B SaaS review site.
  • Create a Capterra profile (free) — Gartner-owned, used heavily by AI engines.
  • Confirm Google Business Profile exists with current name, services, hours.
  • Add each new URL to sameAs in app/layout.tsx Organization schema.

Once all four are live and consistent: +4 points.

PageSpeed & CWV: -2

PSI API was rate-limited during audit. We delivered the structural fixes that improve CWV (proper image dimensions, font-display swap, no client-side LCP content, deferred analytics scripts) but can't score the actual values without a fresh run.

Action: after deploy, run npx unlighthouse-cli --site https://www.yander.ai or PageSpeed Insights on the 5 key pages. Address any LCP > 2.5s or CLS > 0.1 specifically. Expectation: most pages will hit 90+ given the architecture.

AEO: backfill named authors in Sanity (-1)

The author schema is extended and the code emits full Person schema with sameAs links — but the data isn't there yet. Most posts still attribute to "Yander Team" (a generic name). E-E-A-T research shows named individuals with LinkedIn URLs get cited 2-3× more often by AI engines.

Action: in Sanity Studio, create 2–3 real author docs (founder + key contributors) with LinkedIn URLs, then re-assign the top 5–10 blog posts. No code change needed.
